# Live Context speaker-label eval

Measures Pine's speaker labels on real recordings through the app's own code
path: the `pine-live-context` helper (gating, segmentation, CAM++ embeddings,
with the bundled models) and the main-process `SpeakerSession`. Results and
their reading are in `docs/live-context.md` §11.2. Nothing here is compiled or
packaged; audio stays outside the repository.

- `prep.py` builds 16 kHz WAV clips, RTTM references and `<clip>.json`
  (`{lang, duration}`).
- `run.py` plays each clip into the helper's mic source (`--file`, 4× speed),
  keeps its JSONL, replays it, scores it and prints a table.
- `replay.ts` feeds the JSONL to `SpeakerSession` in the order
  `LiveContextService` does and records labels as first shown, at the end of
  the capture and after Stop. `PINE_DIARIZER=<module>` swaps in another
  diarizer module (for before/after runs), `--options` overrides
  `DiarizerOptions`.
- `score.py` reports DER (pyannote.metrics, ±0.25 s collar, overlap scored),
  speaker counts, word-level error, sentence splits and flips; its docstring
  defines each column.

## Reproduce

```sh
S=~/pine-diar-eval   # anywhere outside the repo
mkdir -p $S/dl/jfk $S/dl/libri $S/dl/lunyu
curl -L -o $S/dl/jfk/jfk.flac https://archive.org/download/jfks19620912/jfk_1962_0912_spaceeffort.flac
curl -L -o $S/dl/libri/holly03.mp3 https://archive.org/download/chinachinese_2103_librivox/chinaandthechinese_03_plauchut_64kb.mp3
curl -L -o $S/dl/lunyu/lunyu14.mp3 https://archive.org/download/lun_yu_0801_librivox/lunyu_14_confucius_64kb.mp3

# Python 3.11 venv with numpy, soundfile, sherpa-onnx, pyannote.metrics; ffmpeg on PATH.
# --asr: the ASR benchmark's clips dir; --vad: silero_vad.onnx (sherpa-onnx release).
python -I prep.py --dl $S/dl --asr <asr clips> --vad <silero_vad.onnx> --out $S/clips

# Build the helper and fetch the bundled models (from apps/desktop):
node scripts/build-native.mjs

python -I run.py --clips $S/clips --out $S/runs/new --jobs 3
# Before/after: replay the same helper output with another diarizer module.
PINE_DIARIZER=/path/to/oldDiarizer.ts python -I run.py --clips $S/clips --out $S/runs/new --replay-only
```

The helper's JSONL is cached per clip in `--out`; `--rerun` runs the helper
again, `--replay-only` skips it. A `speakers-state` warning means the helper
throttled itself during the run (run on an idle Mac).
